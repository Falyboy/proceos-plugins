## 🎬 [serie-animee](serie-animee/README.md)

**Votre série de reels en dessin animé. Vous choisissez, Claude fabrique.**

[![Aperçu d'une vidéo fabriquée par serie-animee](serie-animee/docs/images/apercu.jpg)](serie-animee/README.md)

Personnages, décors, voix, bouche qui parle, panneaux d'explication, sous-titres mot à mot, couverture, vérification image par image. Une bibliothèque payée une fois, puis chaque épisode ne coûte que sa voix.

**[→ Voir le plugin](serie-animee/README.md)**
